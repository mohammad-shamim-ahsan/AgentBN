# ==========================================================
# Assumptions
#
# Graph-based:
# 1. Root nodes have no parents and therefore always activate
#    the single column of their prior CPT (column 0).
#
# 2. Every non-root node has a unique active parent-state
#    configuration determined by the realized states of its
#    parents.
#
# Scenario-based:
# 3. Every observed variable has a realized state provided by
#    the scenario.
#
# 4. Every target variable has a realized state provided by
#    the scenario's ground-truth label.
#
# 5. All remaining hidden variables obtain their realized
#    states by deterministic propagation using the
#    maximum-probability state of the active CPT column.
#
# Activation trace:
# 6. Activation tracing is performed only for nodes in the
#    selected relevant subgraph. Additional parent nodes may
#    be included solely to satisfy parent-state dependencies
#    during deterministic propagation.
#
# 7. For every realized node recorded in the activation trace
#    (observed, target, or propagated), the corresponding
#    active CPT column and the selected probability are
#    recorded.
# ==========================================================
