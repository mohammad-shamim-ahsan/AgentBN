# ==========================================================
# Assumptions
#
# 1. Labeled operational scenarios are available, providing
#    the observed evidence and the ground-truth target state
#    needed to identify successful and failed BN inferences.
#
# 2. The BN structure is assumed to be correct and fixed;
#    post-deployment errors considered by AgentBN arise from
#    flawed CPT parameters rather than structural errors.
#
# 3. Flawed CPTs may belong to evidence nodes, intermediate
#    non-evidence nodes, or the target node.
#
# 4. Flawed CPTs responsible for the observed inference
#    failures are assumed to lie on relevant
#    evidence-to-target paths. The current pipeline does not
#    consider flawed CPTs in off-path nodes that do not lie
#    on any relevant evidence-to-target path.
#
# 5. The pipeline supports both predictive and diagnostic
#    reasoning, including cases where evidence is upstream
#    or downstream of the target in the BN.
#
# 6. Each evaluation run uses a designated target variable,
#    and the required scenario evidence is available for
#    inference.
#
# 7. A ground-truth/reference BN is available in the
#    benchmarks for measuring parameter-recovery quality;
#    this reference is used for evaluation, not refinement.
# ==========================================================
