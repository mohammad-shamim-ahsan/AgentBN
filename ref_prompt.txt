## REFINEMENT OBJECTIVE

Make a few changes in the Bayesian Network so that previously failed scenarios become more likely to be classified correctly while preserving behavior on successful scenarios.

Use the previous Bayesian Network as the baseline.

Do not redesign the network structure.

Only refine CPT probabilities.

---

## REFINEMENT RULES

1. START FROM THE PREVIOUS CPTS
* Use the CPT values from {previous_bns} as the starting point.
* Apply incremental modifications.
* Do not rebuild CPTs from scratch.

2. FOLLOW THE CPT DANGER REPORT

For each reported dangerous CPT:
* Treat it as a priority target.
* Focus on the suspicious parameters listed for that CPT.
* Apply the recommended adjustment direction:
  * increase
  * decrease
  * slightly_increase
  * slightly_decrease

Do not modify parameters that are not reported unless required for normalization.

3. PRIORITIZE BY RISK

Apply modifications in this order:
1. High-risk CPTs
2. Medium-risk CPTs

Within a CPT:
1. Rank 1 suspicious parameter
2. Rank 2 suspicious parameter
3. Lower-ranked parameters

Higher-ranked parameters should receive stronger adjustments.

4. USE FAILURE EVIDENCE

For each suspicious parameter:
* Use its failure_count
* Use its success_count
* Use its failure_to_success_ratio
* Use its justification

Repeated failures are stronger evidence than isolated failures.

5. PRESERVE SUCCESSFUL BEHAVIOR

If a CPT region is not implicated by the danger report:
* Leave it unchanged.
* Avoid unnecessary drift.

6. NORMALIZE AFTER EVERY CPT CHANGE

Whenever a parameter is modified:
* Rebalance the remaining probabilities in the same CPT column.
* Ensure the column sums to exactly 1.

## OUTPUT REQUIREMENT

Return a complete Bayesian Network JSON.
Modify only the CPT probabilities necessary to address the reported dangerous CPTs and suspicious parameters.
